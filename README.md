# Hi, I'm Gabriel Chung

Machine-learning engineer and researcher working on language models. I hold two master's degrees, in Artificial Intelligence (MIPT) and Computer Science (Innopolis University), and have spent four years fine-tuning, evaluating and shipping LLMs in Python.

## What I work on

- LLM fine-tuning, prompt engineering and retrieval-augmented generation (RAG)
- Model evaluation, error analysis and experiment design

- Full-stack AI products on Supabase and PostgreSQL

- **Latoken AI Assistant:** LLM and RAG assistant, hackathon winner, 50% faster responses at 1,000+ weekly interactions
- **Educational question generation (MIPT):** LLaMA 3 for adaptive self-study, awarded "Best Presentation" at MIPT's AI-in-education conference

- **Afrimoll:** a marketplace I founded and built end to end

Most of my work lives in private or client repositories, so the public repos here are only a sample. Details and write-ups are on my portfolio.
